# SKILL//TREE

스킬 트리 그 자체가 핵심 성장 구조인 브라우저 성장형 RPG.

## 핵심 구조

- **281개 노드 / 10개 계통**의 초거대 패시브 트리
- 노드 비율은 정확히 **일반 70% / 조건부 20% / 비밀 10%**
- 레벨업으로 SP를 얻고 직접 노드에 투자
- 조건부 노드는 전투 기록을 달성하면 발견
- 비밀 노드는 조건이 숨겨져 있으며 달성 시 정체가 공개
- 각 계통에 액티브 스킬 해금 노드와 게임 규칙을 바꾸는 핵심 노드 존재

## 플레이 루프

전투 → 경험치/골드/SP 획득 → 레벨업 → 스킬 트리 투자 → 조건/비밀 노드 발견 → 보스 격파 → 새 지역 개방 → 더 깊은 빌드 구성

## 포함된 시스템

- 반자동 실시간 전투
- 직접 사용하는 액티브 스킬
- 6개 지역과 지역 보스
- 장비 드롭 및 장착
- 트리 기반 능력치 계산
- 빌드 점수 / 성장 칭호
- 전투 및 발견 기록
- 브라우저 `localStorage` 자동 저장
- 모바일 / 태블릿 반응형 UI
- 서버 및 외부 라이브러리 불필요

## GitHub Pages

`main` 브랜치에 병합되면 `.github/workflows/pages.yml`이 정적 사이트를 GitHub Pages로 배포합니다.

처음 사용하는 저장소에서 Pages가 아직 활성화되지 않았다면 GitHub 저장소의 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 한 번 선택해야 할 수 있습니다.

기본 주소는 Pages가 활성화된 뒤 다음 형태입니다.

`https://namyamnamyam.github.io/SkillTree/`

## 조작

- 전투: 기본 공격 자동
- 액티브 스킬: 화면 버튼 또는 숫자키
- 트리: 드래그 이동, 휠 확대/축소, 노드 클릭 후 SP 투자
- 저장: 15초 자동 저장 + 저장 버튼
